Node.js URL Module
About
This program uses Node.js to get the pathname and query parameters from a URL.

URL
http://localhost:3000/products?category=books&sort=price
Pathname: /products
Category: books
Sort: price
How to Run
Open the terminal in the project folder.
Run:
node app.js
Open this URL in the browser:
http://localhost:3000/products?category=books&sort=price
Output
Page: /products
Category: books
Sorting: price
Use
Query parameters can be used to filter and sort products. For example, category=books shows books and sort=price sorts them by price.
